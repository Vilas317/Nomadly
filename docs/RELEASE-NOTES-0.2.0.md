# Nomadly Starter 0.2.0

## Design refresh
- Introduced a calmer, premium editorial travel visual direction.
- Reworked the homepage hero treatment into a cinematic image-led experience.
- Refined typography, spacing, buttons, navigation, cards, section hierarchy and responsive breakpoints.
- Added subtle interaction states and reduced-motion support.
- Updated brand guidance and added a dedicated design-system document.

## Important
This release updates the UI foundation only. It does not implement live travel inventory, authentication, booking transactions, production moderation or complete product workflows. Demo content and remote image URLs remain illustrative.
